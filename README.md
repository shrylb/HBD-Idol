# Birthday Card for Gwaps

An interactive digital birthday card created for a special 24th birthday celebration of a special someone.

## Features

- Multi-panel interactive card
- Animations and transitions
- Personalized birthday message
- Responsive design

## How to View

The birthday card is deployed at: (https://shrylb.github.io/HBD-Idol/)

## Development

The card is built using:
- HTML5
- CSS3 with animations
- Vanilla JavaScript for interactions

## Structure

- `index.html` - Main structure of the birthday card
- `styles.css` - All styling and animations
- `script.js` - Panel transitions and interactive elements
- `bday.png`, `bday1.png`, `bday2.png`, `bday3.png` - Background images for each panel
